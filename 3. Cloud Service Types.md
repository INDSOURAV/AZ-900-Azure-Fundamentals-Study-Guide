### Cloud Service Type
##### Infrastructure as a Service (IaaS)
Infrastructure as a Service (IaaS) is a cloud service model where you rent basic IT infrastructure such as virtual machines, storage, and networking from the cloud provider, instead of owning physical hardware.

IaaS is the cloud replacement of real-world things such as wires, cables, computers, or hard drives, etc.
1. IaaS Computing – Virtual Machines
   Azure Virtual Machines provide virtual servers in the cloud.
   Example: Instead of buying a physical server, a company creates a VM in Azure to host a website.
	   - You can create and run a virtual computer with your own OS and applications
	   - You control the OS, software, and configurations
2. IaaS Storage – Azure Storage
   Azure Storage provides scalable storage for data.
   Example: A company stores its backup data and files in Azure Storage instead of using physical disks.
	   - Stores files, images, backups, and databases
	   - No need to manage physical hard drives 
3. IaaS Networking – Virtual Networking
   Azure Virtual Network allows you to create private networks in the cloud.
   Example: A company creates a virtual network in Azure to connect its servers securely, just like in a physical office network.
	   - Connect VMs, control traffic, and secure communication
	   - Similar to physical networking (routers, cables, switches)
##### Platform as a Service (PaaS)
Platform as a Service (PaaS) is a cloud service model where you focus only on your application and code, while the cloud provider manages the infrastructure, operating system, and runtime environment.

In simple terms: You build and deploy apps, and the cloud takes care of everything else.
1. PaaS Computing – Azure App Service
   Azure App Service allows you to run applications without managing servers.
   Example: A developer uploads a web application to Azure App Service, and Azure handles hosting, scaling, and updates automatically.
	   - Simply upload your code and configuration to Azure
	   - No need to worry about virtual machines or infrastructure
	   - Built-in features: Auto-scaling, CI/CD integration, Support for containers and Staging and development environments
2. PaaS Storage – Managed Storage / Azure SQL Database
   Azure SQL Database is a fully managed database service.
   Example: A company stores its application data in Azure SQL Database without worrying about database servers or storage hardware.
	   - No need to manage: Servers, Operating systems and Hard disks
	   - Azure handles: Backups, Updates and Performance tuning
3. PaaS Networking
   Services like Azure Front Door, Load Balancer, and Firewall provide networking capabilities as managed services.
   Example: A company uses Azure Front Door to route user traffic globally and improve application performance.
	   - These are software-based networking solutions
	   - No need to manage physical networking hardware
	   - Handle traffic routing, security, and performance
##### Software as a Service (SaaS)
Software as a Service (SaaS) is a cloud model where fully developed applications are delivered over the internet, and users simply use the software without managing anything (no servers, no OS, no platform).
Examples: Microsoft 365 (Word, Excel, Outlook online), Google Workspace and Salesforce
### Serverless
Serverless computing is a cloud model where you do not need to manage servers — you only focus on writing and running your code, while the cloud provider handles the infrastructure.

You pay only for what you use, and there is no need to pre-purchase or reserve resources. It is ideal for event-driven or low-usage workloads.

Example (SQL Database Options)
In Azure SQL Database, there are different pricing models:
1. DTU-based:
	   - Fixed performance levels (e.g., S1, S2)
2. vCore-based:
	   - Choose CPU, memory, and storage manually
3. Serverless:
	   - Automatically scales CPU and memory
	   - Pauses when not in use
	   - Charges only when active

Serverless Services Examples
- Azure Functions:
  Runs event-driven code automatically without managing servers; you pay only for execution time.
- Azure Container Apps:
  Runs containerized applications with automatic scaling and no infrastructure management.
- Azure Kubernetes Service:
  Manages container orchestration and can support serverless patterns with auto-scaling features.
- Azure SQL Database (Serverless tier):
  Automatically scales compute and pauses during inactivity, charging only when in use.
- Azure Cosmos DB (Serverless mode):
  Charges based on operations performed, ideal for low or unpredictable workloads.
##### Serverless Advantages
- No server management
- Automatic scaling based on demand
- Cost-efficient for intermittent or unpredictable workloads
##### Serverless Challenges
- Costs can vary month-to-month based on usage
- Cold starts may cause slight delays when functions run after being idle
