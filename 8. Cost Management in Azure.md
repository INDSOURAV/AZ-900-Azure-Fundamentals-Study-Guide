### Factors that Affect Cost
In Microsoft Azure, cost management is about understanding how your cloud bill is calculated and how you can control it. Azure follows a consumption-based pricing model, meaning you either pay for what you use or choose fixed/committed pricing for cost savings.
1. Resource Type
   The type of service you choose directly affects cost. Different services like Virtual Machines, App Services, Functions, Storage, and Networking all have different pricing models even for similar usage.
   For example, a Virtual Machine costs differently than a Function running the same workload. Similarly, storage and networking are billed separately based on usage patterns.
2. Pricing Model Options
   Azure provides multiple ways to save money depending on your usage pattern:
	   - Pay-as-you-go - Pay only for actual usage
	   - Reserved Instances - Commit for 1 or 3 years to get discounts
	   - Spot VMs - Very cheap but can be interrupted anytime
	So, your pricing choice can significantly change your monthly bill.
3. Service Tier & Configuration
   Many services come in different tiers like Basic, Standard, and Premium. Higher tiers offer better performance, backup options, and features but cost more.
   For example, in App Services, choosing a higher tier gives better scaling and features but increases cost. More CPU, memory, and performance also increase pricing.
4. Region
   The region you deploy in affects pricing. Some regions (like US or Europe) may be more expensive than others.
   Even transferring data between regions can cost money, so where you deploy resources matters for cost optimization.
5. Licensing Costs
   Some services include additional licensing charges, such as Windows Server or SQL Server. These licenses increase the overall cost of running resources.
   However, with Azure Hybrid Benefit, you can reuse existing on-premises licenses to reduce cloud costs.
6. Networking & Bandwidth
   Inbound data into Azure is usually free, but outbound data (leaving Azure to the internet) is charged after a free limit.
   Inter-region data transfer (even within Azure) can also be charged. This makes network design important for cost control.
7. 7. Idle or Unused Resources
   Resources that are running but not fully used still cost money. For example, a Virtual Machine running at 1% CPU is still billed fully.
   Even stopped but not deallocated VMs or reserved resources like disks and IPs can still incur charges.
8. Storage Tiers
   Storage costs depend on access frequency:
	   - Hot (frequent access, higher cost)
	   - Cool (less frequent access)
	   - Archive (rare access, lowest cost but slow retrieval)
	So choosing the right storage tier helps optimize cost.
9. Third-Party Services
   If you use third-party marketplace services or external tools, those costs are added on top of your Azure bill.
10. Monitoring & Optimization Tools
    Azure provides tools like Cost Management + Billing, pricing calculators, budgets, and alerts. These help you track usage, predict costs, and avoid overspending.
### Azure Cost Management
Microsoft Azure provides a Cost Management tool in the Azure portal that helps you track, analyze, and control your cloud spending.
It shows your past invoices and detailed usage reports, so you can understand where your money is going across different subscriptions, resource groups, and services.
##### How it Helps You
One of the main purposes of cost management is to analyze spending over time. You can compare your monthly costs, see trends, and understand whether your usage is increasing or decreasing.
It also provides forecasting, which means it estimates how much you are likely to spend by the end of the current month based on your current usage pattern. This helps you stay ahead of your budget.
##### Budgets and Alerts
You can create a budget limit (for example, $100 per month). Azure will not stop your resources, but it will alert you when you approach or exceed your budget.
These alerts can be sent via:
- Email
- Notifications
- SMS
You can also schedule reports daily, weekly, or monthly to monitor usage regularly.
##### Resource Tags (Very Important)
To track costs properly, Azure uses resource tags, which are key-value labels added to resources or resource groups.
Tags act as metadata, such as:
- Project name
- Department
- Cost center code
- Client ID
For example, if every resource has a project code tag, you can easily track how much each project is spending.
### Resource Tags
Resource Tags in Microsoft Azure are key-value pairs used to add metadata to resources. They help you organize, track, and manage resources without affecting how the resource actually works.
Tags = extra information about a resource (not configuration)

Example:
A storage account can have tags like:
- Owner = James
- Project = E-commerce
- Billing-Code = 12345
This helps identify who owns it, which project it belongs to, and where cost should go.
##### Why Tags are Important
- Organization: Easily group resources by project, department, or environment
- Cost Tracking: Filter costs based on tags (e.g., cost per project or team)
- Governance: Ensure all resources follow company standards
